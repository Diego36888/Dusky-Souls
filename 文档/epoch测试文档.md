## 1. 文档简介

### 1.1 目的
本文档旨在为《Dusky Souls》——一款基于上世纪70年代美国背景的HTML网页游戏——提供详细的测试指导。测试内容涵盖功能、性能、用户体验及兼容性，确保游戏逻辑正确、流程完整、体验流畅。

### 1.2 范围
测试将覆盖以下核心模块：
- 用户系统（登录/注册）
- 剧情对话与分支系统
- 线索收集与推理判定
- 成就系统
- 跨浏览器与设备兼容性
- 重点测试"雨夜谋杀案"主线剧情的逻辑完整性与多结局系统

### 1.3 参考资料
- 《Dusky Souls》项目计划书
- 游戏剧情脚本与角色设定文档

## 2. 测试策略

### 2.1 测试级别
- **单元测试**：针对JavaScript函数、事件处理、状态管理进行测试
- **集成测试**：验证各模块间数据传递（如用户状态与剧情进度同步）
- **系统测试**：端到端测试游戏整体流程
- **验收测试**：模拟真实用户行为，确认游戏可发布

### 2.2 测试类型

| 测试类型 | 重点目标 |
|----------|----------|
| **功能测试** | 验证登录、对话选择、线索收集、结局触发等功能是否正常 |
| **用户体验测试** | 评估界面风格是否符合70年代氛围，交互是否自然，文本是否清晰易读 |
| **界面测试** | 检查UI元素（按钮、图片、字体）是否符合设计稿 |
| **兼容性测试** | 测试在Chrome、Edge等主流浏览器的表现 |
| **逻辑与流程测试** | 验证剧情分支、线索判定、结局触发逻辑是否正确 |
| **性能测试** | 检查资源加载速度、页面响应时间，确保无卡顿 |
