# 游戏项目需求文档 (Game SRS)

## 1. 简介

### 1.1 目的
本说明书用于明确本游戏项目的功能、非功能需求与技术规范，为设计、开发、测试和验收提供依据。本文档面向项目组成员、测试人员及指导教师，确保各方对项目需求达成一致理解。

### 1.2 范围
本项目开发一款基于 Web 的 2D 交互式游戏——**《Dusky Souls》**。  
玩家在游戏中通过操作角色、探索地图、战斗与收集物品，体验黑暗奇幻风格的剧情与成长系统。

游戏包含以下主要模块：
- 用户登录与数据保存系统
- 地图探索与交互机制
- 战斗与生命值系统
- 道具与装备管理
- 音乐与动画表现系统

**不包含内容：**
- 多人联机功能  
- 第三方支付系统  
- 移动端原生应用

## 2. 总体描述

### 2.1 产品视图
《Dusky Souls》是一款 HTML5 网页游戏，玩家可直接通过浏览器游玩，无需安装。  
核心理念是：**通过视觉叙事与探索机制，营造沉浸式游戏体验。**

主要特性：
- 无需后端服务器，数据存储在浏览器本地  
- 响应式UI设计，适配不同分辨率  
- 含音效、动态光影与特效表现  

### 2.2 产品功能

#### 核心模块：
1. **用户系统**
   - 登录、注册、记忆进度
   - 本地存档与读取
2. **地图探索**
   - 自由移动与碰撞检测
   - 触发事件（剧情或战斗）
3. **战斗系统**
   - 敌人AI与血量机制
   - 攻击、防御、技能释放
4. **道具与背包**
   - 道具拾取、装备、使用
   - 背包容量与物品分类
5. **音效与环境**
   - 背景音乐、特定场景音效
   - 环境动态（光线、天气等）

### 2.3 用户特征

| 用户类型 | 特征 | 技能水平 | 使用场景 |
|-----------|------|-----------|-----------|
| 普通玩家 | 喜欢剧情探索类游戏 | 一般计算机能力 | 浏览器单人娱乐 |
| 游戏开发学习者 | 研究HTML/JS交互 | 中等编程能力 | 课程作业、学习项目 |

### 2.4 一般约束

- **技术约束：**
  - 纯前端实现，无需后端依赖  
  - 使用HTML5 + CSS3 + JavaScript  
  - IndexedDB存储用户数据  
- **业务约束：**
  - 免费游戏，无商业化内容  
  - 所有素材均使用可商用或原创资源  
- **法规约束：**
  - 遵守版权与隐私保护法规  

### 2.5 假设与依赖
- 用户使用支持HTML5的现代浏览器  
- 设备具有基本的GPU加速能力  
- 网络稳定但非必须在线

## 3. 详细需求

### 3.1 功能需求

#### F1. 用户注册与登录
- **描述：** 用户可创建角色并保存进度  
- **输入：** 用户名、密码  
- **处理：**
  - 验证唯一性
  - 密码加密保存
  - 初始化角色数据  
- **输出：** 登录成功，进入主界面  
- **异常：**
  - 用户名重复 → “该用户名已存在”
  - 密码错误 → “密码错误”

#### F2. 游戏主界面
- **功能：** 显示角色信息、菜单和场景入口
- **模块：**
  - 左侧状态栏（HP、金币、背包）
  - 中央场景区域（游戏画面）
  - 右下角菜单按钮（地图、存档、设置）

#### F3. 地图探索
- **描述：** 玩家通过键盘或鼠标在地图上自由移动  
- **功能点：**
  - 边界检测与障碍碰撞  
  - 场景切换（如房间、森林、地下）  
  - 随机事件触发（剧情/战斗）

#### F4. 战斗系统
- **描述：** 玩家与敌方单位的实时战斗  
- **内容：**
  - 攻击、防御、技能释放  
  - 敌人AI（巡逻、追击）  
  - 生命值与胜负判定  
- **反馈：**
  - 动画特效、音效提示、战斗结果弹窗

#### F5. 背包与物品
- **功能：**
  - 显示已拾取道具  
  - 道具分类（武器、防具、药品）  
  - 点击使用或装备  
- **奖励机制：**
  - 击败敌人或解谜获得稀有物品  

#### F6. 存档系统
- **描述：** 自动与手动保存游戏进度  
- **实现：** IndexedDB + JSON  
- **触发：**
  - 手动点击“保存”  
  - 场景切换时自动保存  

#### F7. 音乐与动画
- **功能：**
  - 背景音乐循环播放  
  - 动态光影效果  
  - 战斗与场景变化特效

### 3.2 非功能需求

| 分类 | 指标 |
|------|------|
| **性能** | 加载时间 ≤ 3 秒 |
| **可用性** | 新用户 5 分钟内学会操作 |
| **可靠性** | 数据保存成功率 ≥ 99% |
| **可移植性** | 兼容 Chrome / Edge / Firefox |
| **视觉风格** | 暗色哥特风，流畅动画 |
